LeanTab is a clean and customizable new tab for Chrome that keeps your favorite websites, search, and workspace in one place.

Build a start page that works exactly the way you want.

LeanTab features:

• Fast search using your default Chrome search provider
• Search suggestions and local search history
• Convenient tiles for your favorite and frequently used websites
• Folders for organizing large collections of links
• Multiple profiles with separate tiles and settings
• Customizable new tab appearance
• Adjustable tile size and layout
• Clock, date, and personalized greeting
• Settings import and export
• Backup and restore
• Russian and English interface
• Automatic language selection based on your browser language

LeanTab is designed for both everyday browsing and productivity. Create separate profiles for work tools, personal websites, services, social networks, or any other workflow.

Your tiles, folders, profiles, settings, and search history are stored locally in your browser. You can export a backup and restore your workspace whenever needed.

LeanTab replaces Chrome's standard new tab page with a fast, organized, and fully customizable workspace.

Searches are performed using the search provider currently selected in Chrome.

LeanTab — удобная и настраиваемая новая вкладка для Chrome, которая помогает держать любимые сайты, поиск и рабочее пространство в одном месте.

Создайте свою стартовую страницу именно такой, какой она нужна вам.

Возможности LeanTab:

• Быстрый поиск через поисковую систему, выбранную в Chrome по умолчанию
• Поисковые подсказки и локальная история поиска
• Удобные плитки для любимых и часто используемых сайтов
• Папки для организации большого количества ссылок
• Несколько профилей с разными наборами плиток и настройками
• Настройка внешнего вида новой вкладки
• Изменение размера и расположения плиток
• Часы, дата и персонализированное приветствие
• Импорт и экспорт настроек
• Создание резервных копий и восстановление данных
• Поддержка русского и английского языков
• Автоматический выбор языка на основе языка браузера

LeanTab подойдет как для повседневного использования, так и для работы. Можно создать отдельные профили для рабочих инструментов, личных сайтов, сервисов, социальных сетей или любых других задач.

Ваши плитки, папки, профили, настройки и история поиска сохраняются локально в браузере. Вы можете экспортировать резервную копию и восстановить свое рабочее пространство при необходимости.

LeanTab заменяет стандартную страницу новой вкладки Chrome на быстрый, аккуратный и полностью настраиваемый интерфейс.

Поиск выполняется через поисковую систему, которая в данный момент выбрана в настройках Chrome по умолчанию.
